# Velixio visual identity

The generated V/play mark is `app/src/main/res/drawable-nodpi/velixio_logo.webp`, used by the Android launcher, header and library empty state. The adaptive launcher places it on deep ink with safe padding. The header pairs it with a compact lowercase wordmark.

## Generation prompt
Use case: logo-brand. Create a polished original Android streaming-app logo for Velixio. Icon only, no text. A single bold geometric V formed from two flowing cinematic ribbons with a subtle right-facing play cutout integrated into the negative space. Refined electric cyan to luminous violet gradient, crisp confident silhouette, minimal flat vector-like finish, no mockup, no shadows, no extraneous decorations. Centered with generous safe padding for circular Android adaptive icon crops, high readability at tiny sizes. Transparent background. Square composition.

## Interface
Midnight backgrounds, coral actions, large cinematic artwork with gradient-backed titles, restrained text tabs and a rounded navigation dock. Artwork comes from the catalog; portrait covers are center-cropped for the feature and title-page compositions. Controls retain accessibility labels and 48 dp touch targets. Physical-device visual acceptance remains necessary.
