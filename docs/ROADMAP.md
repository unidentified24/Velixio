# Release work

- Verify startup and actual video decoding on ARM Android for every configured connection.
- Check movies, series, animation and shorts; compare Original/Sub choices and available renditions.
- Measure scrolling and artwork loading on a physical device; review layout at small and tablet widths.
- Verify background/PiP, process death, network loss, expired sessions and playback recovery.
- Complete automated checks for the final implementation.
- Review native-library distribution terms and package dependency notices before distribution.
- Keep credentials and private runtime inputs outside the repository; public release requires explicit owner approval.
